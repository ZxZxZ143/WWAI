# Qoldau — фирменный комплект

Комплект подготовлен по утверждённому изображению `source/approved_reference.png`.

## Что использовать

- **Основной логотип:** `svg/qoldau-logo-horizontal.svg` — истинный вектор, прозрачный фон. Для сайта, презентации, интерфейса.
- **Знак без названия:** `svg/qoldau-symbol.svg` — кошка, объятие/сердце и звезда, для компактных мест.
- **Вертикальный логотип:** `svg/qoldau-logo-stacked.svg` — для обложек и узких композиций.
- **Словесный знак:** `svg/qoldau-wordmark.svg` — только надпись без символа.
- **Монохромный вариант:** `svg/qoldau-logo-monochrome.svg` — один бордовый цвет.
- **Вариант на кремовом фоне:** `svg/qoldau-logo-on-cream.svg`.
- **Иконка приложения:** `app-icons/qoldau-app-icon-1024.png` — основной iOS/App Store мастер 1024×1024, квадрат без скругления (скругляет ОС).
- **Цветовые варианты иконки:** `app-icons/qoldau-app-icon-light-1024.png`, `qoldau-app-icon-blush-1024.png`, `qoldau-app-icon-burgundy-1024.png`.
- **Android/web sizes:** `app-icons/qoldau-app-icon-{192,512}.png` и другие размеры.
- **Favicon:** `favicon/favicon.svg`, `favicon/favicon.ico`, PNG 16/32/48.
- **Соцсети/презентация:** `previews/qoldau-social-banner-1200x630.png`.
- **Общий обзор:** `previews/qoldau-brand-overview.png`.

## Качество и исходник

SVG-файлы **действительно состоят из редактируемых векторных контуров** — текст также преобразован в контуры, поэтому нет зависимости от шрифта. Это автоматическая трассировка утверждённого растрового PNG, а не оригинальный исходный вектор дизайнера. Мелкие градиенты/полутона оригинала упрощены до четырёх фирменных цветов, края в SVG слегка сглажены. Для абсолютно точного типографического исходника нужен оригинальный файл дизайнера, если он существует.

Полноцветные SVG лучше использовать на светлом фоне: светлая мордочка кошки формируется негативным пространством. Для тёмного фона предусмотрена кремовая медальонная версия иконки. Не меняйте пропорции, не перекрашивайте маскотов в основной логотип, не ставьте логотип слишком близко к краям.

Иконка на весь экран квадратная, **без скругления углов**, чтобы iOS/Android самостоятельно применяли необходимую форму. Файлы можно использовать в Lovable как статические ассеты.
