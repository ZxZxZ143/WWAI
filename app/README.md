# Қолдау: приложение

Рабочая версия MVP по [функциональной спецификации 05](../docs/05_FUNCTIONAL_SPEC.md) с фронтендом и бэкендом. Все профили синтетические, из [docs/02](../docs/02_DEMO_SCENARIOS.md).

## Запуск

Нужен Node.js 22.13 или новее.

```bash
cd app
npm install
npm start
```

Откройте http://localhost:8787.

AI работает через OpenAI. Ключ кладётся в файл `app/.env`, который git игнорирует:

```
OPENAI_API_KEY=...
```

Модели по умолчанию: `gpt-5.4-mini` для разговора, разбора и сводки, `gpt-4o-mini-transcribe` для распознавания речи, `gpt-4o-mini-tts` для озвучки. Их можно сменить переменными `OPENAI_CHAT_MODEL`, `OPENAI_STT_MODEL`, `OPENAI_TTS_MODEL`, `OPENAI_TTS_VOICE`. Ключ живёт только на сервере и в браузер не попадает. Вместо OpenAI можно задать `ANTHROPIC_API_KEY`, тогда ответы пишет Claude, а голос берётся из браузера. Без ключей приложение отвечает заготовленными примерами.

## Как устроено

- `server/server.js`: HTTP-сервер на `node:http`, JSON API и раздача фронтенда. Цвета и шрифты берутся из `design/qoldau-kit/project/tokens.json`.
- `server/db.js`, `server/seed.js`: SQLite на встроенном `node:sqlite`, файл `app/data/qoldau.db`, демопрофили Алии и Миры.
- `server/domain.js`: правила из 05. Позы маскота, формула процента плана, аналитика 7/14/30, подбор опоры.
- `server/ai.js`: разговор, разбор наблюдений и сводка через Claude, деморежим без ключа, ветка срочной помощи X.
- `public/`: фронтенд без сборки. Экраны O1–O5, T, M, C, V, S, P, H, U, D, X.

Голос записывается в браузере только по кнопке, распознаётся и озвучивается через OpenAI. Если сервис недоступен, работает голос браузера. Аудио разговора не сохраняется.

## Проверка

```bash
npm test
```

Тесты проверяют числа и правила из 02 и 05 через настоящий HTTP API. Среди них коды записей A-M1, A-S1, A-F1, P-A1, B-03, S-B1, процент 0% → 33% → 67% → 100% или без процента, аналитика 7/14/30, неизменность R-01, изоляция профилей, удаление и ветка X.

## Что не закрыто

- В интерфейсе нет подписей «Демонстрационные данные» и «Деморежим», хотя 02 их требует: их убрали по решению команды. Профили Алии и Миры по-прежнему синтетические.
- Голос с настоящего микрофона проверялся только через API (речь → текст), не вживую на устройстве показа.
- Экранные дикторы и казахская раскладка вручную не проверялись.
