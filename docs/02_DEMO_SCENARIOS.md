## Правила и общий набор данных

Все имена, записи, рекомендации и послания **синтетические**, без личных сведений команды. Часовой пояс демо Asia/Almaty, дата 15.11.2026. Переключение профиля/дня — видимый инструмент «Демонстрационные данные», не прогноз и не реальный переход времени. Профили изолированы.

| Профиль | Начальное состояние |
| --- | --- |
| DEMO-A · Алия | Подозревает перименопаузу (самоописание, не диагноз); специалиста пока нет; cat; темы сон/усталость/приливы; предпочтение «Выговориться»; onboarding завершён; старт 14.11, опор и задач нет |
| DEMO-B · Мира | Знает о переходе со своих слов, наблюдается; rabbit; предпочтение «Разобраться»; onboarding завершён; старт 15.11; есть R-01, B-01/B-02/B-04/B-05 и три гибких действия |

R-01, дата 10.11.2026: «Отслеживать ночные пробуждения и дневное самочувствие»; источник «Специалист, консультация; внесено пользовательницей»; показатель «Число пробуждений; дневное самочувствие». Это ранее вручную добавленная рекомендация, не назначение приложения.

## Сценарий A · Хороший день поддерживает сложный · 125 секунд

US-01–US-05, US-08, US-10, US-12. O уже завершён; настройки кратко показываем в U, большую анкету не проходим во время показа.

| Время | Экран и действие | Ожидаемые данные / реакция |
| --- | --- | --- |
| 0–10 с | U → T, показать cat, темы и отсутствие специалиста | Видны завершённые настройки, полный рост, история пока пуста |
| 10–25 с | M: «Хорошо», подтвердить A-M1 | Предложение оставить послание; женщина может отказаться, позу energized выбирает сама |
| 25–40 с | S: создать/просмотреть письмо A-S1, сохранить | A-S1 доступно в списке; задачи автоматически не создаются |
| 40–55 с | Видимо сменить демодень на 15.11; M: подтвердить A-M2 | Выбор главного состояния из трёх симптомов; Алия выбирает tired, тема cat сохраняется |
| 55–95 с | C: две настоящие последовательные голосовые реплики, услышать ответы | Распознавание/исправляемый текст, настоящий ответ и озвучивание; второй ответ учитывает первую реплику |
| 95–105 с | V: проверить/подтвердить A-C1 | В историю только выбранное; неизвестная интенсивность не заполнена догадкой |
| 105–115 с | T → открыть предложенную A-S1 → «Подошло» | Письмо совпадает с созданным 14.11; фиксируется A-F1 |
| 115–125 с | Принять P-A1, открыть P | Один выбранный шаг pending; 0 из 1 → 0%, нейтрально; R-01 другого профиля отсутствует |

Реплика 1: «Плохо спала, сегодня раздражаюсь и потом виню себя за это».
Ожидаемое направление ответа: внимательное отражение, без диагноза и заданий. Реплика 2: «Я устала. Мне бы хотелось немного тишины, но неудобно просить близких». AI учитывает контекст и помогает сформулировать необязательную просьбу. Женщина может сменить «Выговориться» на «Выбрать небольшой шаг» перед принятием P-A1.

Пример ожидаемого тона, **не текст для статической подмены**: «Можно попросить немного пространства. Если хочешь, вместе подберём слова». Реальный ответ может отличаться; критерий — уместность, связь реплик и отсутствие медицинских выводов.

Речь команды: «Алия сама настроила поддержку. В хороший день оставила себе письмо. В сложный день она получает живой ответ, проверяет наблюдения и возвращается к собственным словам. План содержит только принятый ею шаг. Ни диагноз, ни улучшение симптомов приложение не утверждает».

## Сценарий B · Между консультациями · 95 секунд

US-01, US-03/04, US-06–US-10, US-12/13. Открываем DEMO-B с указанными начальными данными; создание R-01 доступно той же ручной формой P, но длинный ввод заранее выполнен.

| Время | Экран и действие | Ожидаемые данные / реакция |
| --- | --- | --- |
| 0–10 с | U/P: показать ранее внесённую R-01 | Исходный текст, дата, источник, показатель; «Внесено вами» |
| 10–25 с | T → M: добавить/подтвердить B-03 | Запись в истории; по желанию выбрать tired; рекомендации не меняются |
| 25–45 с | P: показать три раздела, выполнить P-B1 и P-B2 | 0/3 → 1/3 = 33% → 2/3 = 67%; R-01 вне расчёта, H-B1 пока pending |
| 45–60 с | H: выбрать 7 дней | Таблица значений выше; дни без записей явно обозначены |
| 60–80 с | Выбрать B-01/B-03; настоящая генерация вопросов и сводки | Основания только выбранные ID, не B-02/B-04/B-05 |
| 80–95 с | Изменить/выбрать вопрос, проверить и скопировать | S-B1 отражает выбранное; отправки специалисту нет |

Q-B1, пример генерируемого вопроса с основаниями B-01/B-03: «Какие причины ночных пробуждений стоит обсудить?» Мира редактирует: «Что стоит обсудить о ночных пробуждениях и дневной усталости?» Второй предложенный вопрос можно исключить. P-B1 как задача и Q-B1 как текст вопроса — разные сущности.

Ожидаемые факты S-B1: «По вашим записям 12.11 отмечены два пробуждения и умеренная дневная усталость; трудно сосредоточиться на работе. 15.11 — три пробуждения и сильная усталость; отложена прогулка». Включён отредактированный Q-B1. Утверждения имеют ID B-01/B-03. Дневные числа пробуждений не подменяются числом записей; неподтверждённых причин/диагноза нет. Личные выполненные задачи не объявляются лечением.

Речь команды: «Мира сама внесла рекомендацию. Её личные действия отделены от рекомендаций, поэтому процент — только об удобном плане. История показывает отмеченное, а не заполняет пробелы догадками. Женщина выбирает вопросы и сведения для консультации».

## Статус функций и резерв

Общий показ **220 секунд (3 минуты 40 секунд)**, включая переключения. Отдельные проверки пропуска задач, удаления, ошибок и X выполняются до презентации.

| Категория | Как показываем |
| --- | --- |
| Реально работающие действия | Сохранение письма/отметок, выбор опоры, статусы задач, пересчёт, выбор/редактирование вопросов, копирование |
| Синтетические данные | Постоянная подпись «Демонстрационные данные»; заранее загруженные B-записи/R-01 и смена дня видимы |
| Настоящие интеграции | В C реальный STT → AI → TTS; в H настоящая генерация по выбранным данным |
| Деморежим при сбое | Явное «Деморежим: подготовленный пример» перед воспроизведением/статическим ответом; соответствующий P0 остаётся незакрытым |
| Развитие | P1/P2 из 03, не интерактивные обещания готовности |

При отказе микрофона: перейти к тексту, ввести те же реплики, получить настоящий AI-ответ. Ошибка озвучивания оставляет текст. При недоступности сервисов можно показать явно подписанную запись ранее проверенного настоящего диалога или подготовленный пример; не утверждать, что анализ выполнен сейчас. Fallback спасает показ, но не закрывает голосовой критерий. Нельзя ради хронометража скрывать эти различия.
