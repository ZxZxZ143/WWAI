# Mascots

Шесть персонажей Peri в состоянии «Бодрость», статичный SVG 200×220 на круглом фоне. Это упрощённые векторные наброски по листам персонажей, не финальная иллюстрация.

Используйте их в выборе персонажа и как запасной вариант, когда анимация недоступна. Цвета зашиты в файл, `currentColor` не применяется. Живые версии со всеми состояниями собраны в `prototypes/peri-mascot-animations.html`.
