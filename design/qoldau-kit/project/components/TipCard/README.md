# TipCard

Карточка даёт одну мысль на сегодня и не требует её выполнять.

- Внутри: `q-label` «Совет на сегодня», текст `q-tip__text` до 160 знаков, строка-источник в `q-tip__meta` и, если совет подготовлен заранее, `q-demo`.
- Действия необязательны: «Сохранить в план» и «Не подходит». Отказ ничего не ломает и помогает приложению.
- Тон взрослый и тёплый. Нельзя: «Не забудьте!», «Вы должны», «это просто гормоны», восклицательный оптимизм.
