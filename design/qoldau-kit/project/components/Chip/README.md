# Chip

Чип отмечает симптом или наблюдение одним касанием.

- Выбор симптомов: `<button class="q-chip" aria-pressed>`. Выбранный чип получает `aria-pressed="true"`, точку и заливку `wine-soft`.
- Подтверждённое наблюдение: `q-chip q-chip--confirmed`, галочка и `olive-soft`. Только оно попадает в историю и сводку.
- Предложение приложения до проверки: `q-chip q-chip--suggested`, пунктир и вопросительный знак в тексте. Неподтверждённое предложение никогда не выглядит как факт.

Текст чипа короткий, до трёх слов, со строчной буквы после первой.
