# Entry

Карточка одной сохранённой записи: рассказ её словами и подтверждённые наблюдения отдельно.

- Порядок: `q-state`, дата и способ ввода, затем рассказ `q-entry__quote` целиком, затем подтверждённые наблюдения `q-chip--confirmed`, затем влияние на жизнь.
- Рассказ не заменяется списком наблюдений. Неподтверждённые предложения в карточку не попадают.
- Действия «Дополнить» и «Убрать» стоят под карточкой как `q-btn--quiet`.
