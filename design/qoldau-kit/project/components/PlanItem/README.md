# PlanItem

Элемент личного плана с явной подписью происхождения.

- `q-plan--step`: действие, которое выбрала она сама. `q-plan--question`: вопрос к консультации. `q-plan--specialist`: рекомендация специалиста, подпись строго «Рекомендация специалиста · внесено вами», с источником и датой.
- Рекомендацию специалиста приложение не меняет и не переписывает. Предложения приложения попадают в план только после выбора.
