# Button

Кнопка запускает одно действие и называет его глаголом.

- `q-btn q-btn--primary`: одно главное действие на экране. На главной это «Как вы сегодня?» в размере `q-btn--lg`.
- `q-btn q-btn--secondary`: сохранение и второстепенные действия рядом с главной.
- `q-btn q-btn--quiet`: выход без последствий, например «Завершить без шага» или «Отменить».
- Во время сохранения кнопка получает `disabled` и текст «Сохраняем…», чтобы запись не ушла дважды.

Текст кнопки пишет пользовательница, а не система: «Сохранить запись», а не «Отправить данные». Минимальная высота 44px.
