# StateMark

Метка показывает состояние маскота за день: форма, цвет и слово вместе.

- Шесть состояний повторяют листы персонажей: Бодрость (круг, `olive`), Задумчивость (ромб, `lilac`), Усталость (черта, `clay`), Прилив (треугольник, `clay`), Тревога (кольцо, `wine`), Отдых (скруглённый квадрат, `olive`).
- `q-state` с текстом используется в карточках. Одна `q-mark` без текста допустима только в дне календаря, у которого есть `aria-label` со словом.
- Состояние выбирает пользовательница или оно следует из подтверждённой записи. Посещаемость и симптомы его не ухудшают.
