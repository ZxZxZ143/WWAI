# Calendar

Календарь показывает историю по дням и открывает день, чтобы посмотреть или дополнить записи.

- Неделя начинается с понедельника, дни недели строчными `пн … вс`, месяц в `display-lg`.
- День `q-day` содержит число и `q-day__marks` с метками состояний (`q-mark`). У дня без записей нет меток и нет упрёка: пропуск не считается ошибкой.
- Сегодня: `q-day--today` с подписью «сегодня». Выбранный день: `aria-selected="true"`, заливка `wine`. День с внесённой рекомендацией специалиста: рамка `navy`, класс `q-day--rec`.
- Будущие дни `q-day--future` не открываются. Прошлые открываются всегда, их можно дополнять и исправлять.
- Каждый день это кнопка с `aria-label`, например «12 ноября, 1 запись, Усталость». Легенда `q-legend` объясняет метки словами.
- На десктопе рядом с сеткой стоит панель выбранного дня, на телефоне она уходит под сетку.
