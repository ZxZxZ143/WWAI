# Қолдау · Qoldau

**Қолдау** («Поддержка») — приложение эмоциональной поддержки для женщин в период перименопаузы и менопаузы. Оно помогает выразить переживания, выбрать формат поддержки и сохранить личные опоры и наблюдения.

Проект готовится для **Women Who AI FemTech Buildathon**, Narxoz University, Алматы. На разработку отведено около трёх часов.

**Текущий этап — документация перед разработкой MVP.** Приложение ещё не реализовано; стек не выбран. Визуальные материалы ожидаются от коллеги, затем команда подготовит UI-kit и перейдёт к разработке.

Читайте документы по порядку:

1. [Контекст продукта](docs/00_PRODUCT_CONTEXT.md) — аудитория, актуальные решения, границы и ожидания.
2. [User stories](docs/01_USER_STORIES.md) — семь историй и проверяемые критерии приёмки.
3. [Демонстрационные сценарии](docs/02_DEMO_SCENARIOS.md) — два пути, синтетические данные и речь для показа.
4. [План сборки MVP](docs/03_MVP_BUILD_PLAN.md) — экраны, данные, три часа работы и ручная проверка.

Документы описывают согласованное направление и будущие требования, а не уже работающие функции. Следующий этап — согласование визуальных материалов и UI-kit; реализация приложения выполняется отдельной задачей.
